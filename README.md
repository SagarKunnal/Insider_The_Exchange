# Haunted by Yourself

### Team Name
insiders

### Track Number & Name
Track II — Learning / Adaptive Behavior

### Problem Statement Name
The Haunted Algorithm

### Idea
Haunted by Yourself is a Pac-Man-style maze chase where three ghosts study different layers of how you play—the routes you repeat, the spots where you hesitate, and how you panic when cornered—without using machine learning. As they learn, they draw their memory directly onto the maze floor as visible trails and set telegraphed ambushes ahead of your usual escapes, so the only way to survive and score high is to break your own patterns. Every run ends with a Habit Autopsy that tells you, in plain terms, exactly what the ghosts figured out about you.

### How to Run

**Prerequisites**
- Node.js (v18 or later) and npm
- A modern desktop or mobile web browser

**Installation Steps**
1. Clone the repository and enter the project directory:
   ```bash
   git clone https://github.com/SagarKunnal/I_The_Exchange.git
   cd I_The_Exchange
   ```
2. Install dependencies:
   ```bash
   npm install
   ```

**Commands to Run Locally**
- Start the local development server:
  ```bash
  npm run dev
  ```
  Open the local URL shown in the terminal (default: `http://localhost:5173`).
- Run the test suite:
  ```bash
  npm test
  ```
- Build the production bundle:
  ```bash
  npm run build
  ```
